可以体验什么

侧栏折叠、搜索展开、标签切换、页码跳转和缩放布局。批注、框选、AI 与原位解释仅有交互示意，不读写 PDF，不调用模型。

现有界面的重复页码、缩放、关闭入口已在两个方案中合并。测试样例按钮、阶段提示与长篇帮助不进入常驻阅读区。

设计参考与共同原则

参考 Edge 的工具栏与目录入口、Acrobat 的快捷工具和可收起侧栏、Firefox 的缩略图与集中页码/缩放。以下是结构参考，不是本产品兼容性验证。

Microsoft Edge · Acrobat 快捷工具 · Acrobat 侧栏 · Firefox 阅读器

  • 页面滚动、侧栏滚动各自独立；不劫持滚轮，不依赖方向手势。
  • 图标有名称、提示和键盘焦点；页码与缩放只保留一个主要入口。
  • 窄窗侧栏改为可关闭抽屉；桌面宽窗左右可以同时展开，关闭后完整归还阅读宽度。
  • 选中文字或框选区域后才出现提问/解释入口；原位解释的取消、确认与 PDF 保存是不同操作。
  • 当前 PDF 上下文默认开启，同目录默认关闭；模型与 Default 风格放在 AI 栏内。
  • 批注工具按模式展开；未来未保存状态放在文档标签，显式保存放在菜单及快捷键，能力未就绪时不放假按钮。
  • 正式重构只调整界面，保留既有 PDF 渲染、搜索、标签隔离、位置恢复和资源释放逻辑。
